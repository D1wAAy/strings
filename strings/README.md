strings (Т118)

Функции для очистки, проверки и разбора строк. Без регулярных выражений,
классов. Учебные данные, никаких реальных паролей и телефонов.

Запуск:python3 text_tools.py

Функции ничего не печатают и input не спрашивают — примеры выводит блок 
if __name__ == "__main__":.

Функции:
- clean_notice(text) — убрать пробелы/табуляции/переводы строк с краёв, серии пробелов между словами сжать в один
- has_bug(text) — True, если "bug" есть в любом регистре
- valid_nickname(text) — ник: 4–12 символов, первая латинская буква, далее латиница/цифры/_
- preview(text, limit) — очистка + обрезка до limit символов с "..."
- parse_event(line) — запись GROUP;STATUS;MESSAGE → список или None
- failures(lines, group) — сообщения FAIL для группы
- search_messages(lines, query) — поиск в сообщениях без учёта регистра (бонус, задание 8)
